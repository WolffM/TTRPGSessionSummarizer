# TTRPG Session Summarizer: trivia

Each fact names the commit or sheet it comes from.

## Trivia

- **Born under another name.** The repo was first called
  `ytTranscriptToWhisper`: its own README said so until a May 2024 rewrite
  (`09f4080`), and a March 2024 merge commit still names that remote URL
  directly (`f747242`).
- **An AI README's placeholder, committed.** That same 2024-05-20 rewrite
  pasted in an Installation section telling readers to
  `git clone [invalid URL removed]` — literal template text — and `cd`
  into a folder name, `pathfinder-session-summarizer`, that was never this
  repo's actual name. It sat in the README for 44 days before being
  deleted (`09f4080`, removed in `a7f8a1d`).
- **A whole busy day.** The single busiest day in the project's history,
  2026-01-07, was six commits: the owner adding a static-analysis
  workflow, followed the same day by five Copilot-authored pull requests
  with lint fixes (`149dd7b`, `b3e493d`, `c1a6e06`,
  `7a0e32d`, `4521da5`, `3cc4091`; fact sheet, 2026-11-16).
- **541 days of silence, 652 for the code itself.** The repo went 541
  days with no commits at all, from a README edit on 2024-07-03
  (`a7f8a1d`) to a two-line auto-commit on 2025-12-26 (`08346f1`).
  `transcript.py` went even longer without a human touching it: 652 days,
  from `59b62ab` on 2024-03-14 to that same auto-commit (fact sheet,
  2026-11-16).
